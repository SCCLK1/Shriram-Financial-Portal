Frequently asked
How long does generation take? +
Typically 15–45 seconds. The system fetches data from multiple sources simultaneously, processes it, and renders the image. If some data sources are slow (like during market open/close), it may take slightly longer.
What if the market is closed or a value is missing? +
The system will show a dash (—) for any metric it couldn't fetch. You can use the Manual Override feature in the sidebar to enter any missing values before generating, so the card always looks complete.
Is the data accurate? Where exactly does it come from? +
Yes — the data comes from Yahoo Finance (yfinance), which sources from official exchange feeds. It's the same data used by professional financial platforms. There may be a 15-minute delay during live trading hours, which is standard across all financial data providers at this price point.
Can we change what logo appears on the card? +
Yes. In Admin Settings → Branding & Logos, you can select which Shriram entity logo appears (AMC, Wealth, Insights, or Financial Services), and you can also upload a new logo image at any time. The change takes effect immediately for the next generation.
How are old cards saved? Can we go back? +
Every generated card is automatically archived. You can access the last 15 days of cards from the Archives button on the main screen. Each archive entry shows the card image with its original date and timestamp.
Does this work on mobile? +
Yes. The portal is fully responsive and works on any phone browser. You can generate, preview, copy, and share the card all from your mobile device — no desktop needed.
