Data Guardrails & Validation

Every fetched value passes through strict range validation limits before reaching the HTML template. Values outside reasonable bounds are safely logged and omitted to protect report integrity.

VAL_BOUNDS = {
  "bse": (40000.0, 180000.0),
  "nse": (12000.0, 55000.0),
  "fii": (-30000.0, 30000.0),
  "brent": (30.0, 180.0),
  "vix": (5.0, 60.0),
}

Drag & Drop Layout Customizer

Users can reorder DOM elements, adjust fonts, hide elements, or apply custom colors directly from the browser dashboard. Selections are safely persisted in SQLite and layout_overrides.json.

// Dynamic class stripping prevents layout grid shift
selector = selector.replace(/\.(up|down|flat|pos|neg)/g, '');
render.py safe_reorder(parent, dom_orders)

Auto-Archiving & Restoration

Every report run automatically snapshots generated PNG cards and HTML source into output/versions/<YYYYMMDD_HHMMSS>. Past versions can be previewed or restored with 1 click.

POST /api/version/restore/<version_id>
- Restores layout_overrides.json
- Restores active card_daily.png
- Triggers instant live dashboard reload
